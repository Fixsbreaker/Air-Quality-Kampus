# Доска задач (Trello)

Силлабус практики требует владения инструментами управления задачами — Jira,
Trello, Azure DevOps или аналогами. Ниже готовая структура доски и полный
список карточек: их достаточно перенести в Trello и двигать по колонкам по
ходу работы, чтобы к защите была видна история.

Trello выбран потому, что бесплатен без ограничений на число карточек, не
требует администрирования и открывается по ссылке — комиссии удобно показать.
Jira для команды из двух человек избыточна.

## Настройка доски

1. Создать доску **KBTU Air Quality Kampus**.
2. Колонки: `Бэклог` → `В работе` → `На ревью` → `Готово`.
3. Пригласить второго участника (Share → Invite).
4. Метки: `данные` (синяя), `backend` (зелёная), `ML` (фиолетовая),
   `frontend` (жёлтая), `бот` (оранжевая), `инфраструктура` (серая),
   `документы` (красная).
5. Включить Power-Up **GitHub**, привязать репозиторий. Тогда в карточке
   видно связанные коммиты и Pull Request — именно это и требуется показать.

## Правила работы

- Одна карточка = одна ветка = один Pull Request.
- Название карточки совпадает с названием ветки, чтобы связь была очевидна:
  карточка «Клиент Open-Meteo» → ветка `feature/ingestion-openmeteo`.
- Карточка переезжает в `На ревью`, когда открыт Pull Request, и в `Готово`
  после слияния.
- В карточке указывается исполнитель — так вклад каждого виден на доске.
- Чек-лист внутри карточки: «код», «тесты», «документация», «ревью пройдено».

## Что показать на защите

Скриншот доски с заполненной колонкой `Готово` и открытой карточкой, где видны
связанные коммиты через Power-Up GitHub. Это закрывает сразу два требования
силлабуса: владение трекером задач и работа в системе контроля версий.
