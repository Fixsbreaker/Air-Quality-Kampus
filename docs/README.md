`COMMIT_PLAN.md` и `COMMIT_RUNBOOK.md` — рабочие документы команды, в репозиторий
их выкладывать не нужно.

Отчёты и дневники подготовлены в Markdown и переносятся в Word без переформатирования.
Требования кафедры: Times New Roman 14 пт, одинарный интервал, поля 30/15/20/20 мм,
объём 15–20 страниц.

Даты, наименование организации, группы и фамилии оставлены пропусками вида
`\_\_\_\_\_\_` — заполняются по фактическому месту прохождения практики.

## Что подготовить дополнительно для защиты

Материалы, которые нужно собрать самостоятельно — их нельзя сгенерировать заранее:

1. **Снимки экрана** дашборда (настольная и мобильная раскладка), Swagger UI,
   переписки с Telegram-ботом, вывода `pytest`, зелёного конвейера в GitHub Actions.
2. **Отзыв-характеристика** от руководителя практики на предприятии с печатью
   организации.
3. **Подписи** руководителя практики в дневнике по каждому дню.
4. **Титульный лист** по действующей форме кафедры — в отчётах приведён шаблон,
   но форма могла обновиться.
